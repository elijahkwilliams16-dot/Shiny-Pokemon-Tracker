# Shiny Pokémon Tracker

A Python-based application that allows users to record and view shiny Pokémon
across different games and generations.

## Features
- Add shiny Pokémon with game, method, and date
- Automatically determines generation based on game
- Prevents duplicate entries
- Persistent storage using JSON

## Technologies Used
- Python 3
- JSON for data persistence

## Future Improvements
- Search and filtering
- Web interface
- AI-generated summaries
